## 1. High-Frequency Spelling Confusions (المتشابهات الصوتية)

| What You Wrote (الصوت التقريبي) | Exact Spelling (الكتابة الصحيحة) | Meaning & Memory Hook |
| :--- | :--- | :--- |
| `grammer` | **grammar** | Ends with **-ar** (like *radar* or *calendar*). |
| `calender` | **calendar** | Ends with **-ar**. |
| `cashing` | **caching** | *Cash* = فلوس 💵. *Cache* = ذاكرة تخزين مؤقتة 💾. |
| `freez` | **freeze** | Ends with silent **e**. |
| `looked in` | **locked in** | *Locked in* = full focus / monk mode 🔥. |
| `even thought` | **even though** | *Thought* = فكرة أو ظن. *Though* = بالرغم من. |
| `memize` | **memorize** | Root is *memory* ➔ *memorize*. |
| `credints` | **credits** | Root is *credit*. |
| `arn't` | **aren't** | Contraction of *are not*. |
| `denial fo service` | **denial of service** | Typo *fo* ➔ *of*. |
