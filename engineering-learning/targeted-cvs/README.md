## ⚡ Deployment Protocol for Job Applications
1. Read the target Job Description (JD).
2. If the JD requires 80%+ React/Next/UI ➔ Deploy **Variant A**.
3. If the JD requires Backend/APIs/Database/Fullstack ➔ Deploy **Variant B**.
4. Test match rate on Jobscan / ATS scanner before submitting.
