# Mandatory Challenge-to-Notes Sync Rule

> **Scope**: All daily engineering challenges and architectural milestones.

## Directive
- **Never Stop at Code**: Solving a challenge and getting an exit code 0 is only Step 1 of the pipeline.
- **Mandatory Synchronization**: Every completed challenge MUST immediately be synthesized into:
  1. A structured Concept Card in `engineering-learning/LEARNING_NOTES.md` following the 3-part card standard (Intuition for 10yo, Production Reality & Code snippet, 3-Step Reality Check / Interview script).
  2. The Table of Contents in `LEARNING_NOTES.md`.
  3. The index under Section 1 in `MASTER_KNOWLEDGE_BASE.md`.
- **Zero Orphaned Challenges**: No challenge may remain as an undocumented code artifact in `my-solutions/`.
- **Automatic Push**: Stage, commit, and push both documentation files and the solution together.
